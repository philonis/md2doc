# Assets 文件夹

此文件夹用于存放应用的资源文件。

## 需要的文件

请在此文件夹中添加以下图片文件：

1. **icon.png** - 应用图标
   - 尺寸: 1024x1024 像素
   - 格式: PNG
   - 用途: iOS 和 Android 应用图标

2. **splash-icon.png** - 启动画面图标
   - 尺寸: 200x200 像素或更大
   - 格式: PNG
   - 用途: 应用启动时显示的图标

3. **adaptive-icon.png** - Android 自适应图标
   - 尺寸: 1024x1024 像素
   - 格式: PNG
   - 用途: Android 自适应图标前景

4. **favicon.png** - Web 图标
   - 尺寸: 48x48 像素
   - 格式: PNG
   - 用途: Web 应用图标

## 图标设计建议

- 使用简洁的设计，避免过多细节
- 确保图标在小尺寸下仍然清晰可辨
- 使用品牌色彩（黑色背景 + 白色文档图标）
